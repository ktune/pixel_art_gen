# Retro Pixel Art Generator 🎨

A Python desktop application to convert images into 8-bit retro-style pixel art using Tkinter and Pillow.

## ✅ Features
- Upload images using file dialog or drag-and-drop
- Adjustable pixel size and color depth
- Real-time preview of pixel art
- Save the converted image
- Full-screen pixel art preview

## 📦 Requirements

Install with:

```bash
pip install -r requirements.txt
